	$	CONCEPT OF AUTOMATIC SEMICOLON INSERTION.
	
		function add(a, b) {
			return
			a + b;
		}
		
		You might look at this and think:
		
		"It's the same thing. return means return a + b."
		
		But it is not the same thing.

		JavaScript sees the line break immediately after return.

		Because of Automatic Semicolon Insertion, JavaScript effectively changes it to:

		function add(a, b) {
			return;
			a + b;
		}
		
		
	$	Short-circuit evaluation means JavaScript stops evaluating an expression as soon as it already knows what the final result must be.

		This mainly happens with:

		&& — logical AND
		|| — logical OR
		?? — nullish coalescing

		The key idea is:

		JavaScript evaluates from left to right and may stop before evaluating everything.
		
		When you see:

		A && B

		think:

		"If A is falsy, give me A. Otherwise, give me B."

		When you see:

		A || B

		think:

		"If A is truthy, give me A. Otherwise, give me B."

		When you see:

		A ?? B

		think:

		"If A is not null or undefined, give me A. Otherwise, give me B."

		That is the core of short-circuit evaluation.
